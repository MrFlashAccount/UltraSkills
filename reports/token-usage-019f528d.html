06 / Method

Что именно посчитано

Агрегаты восстановлены из локальных JSONL rollout logs по UUID.

Правила интерпретации

  • Runtime: workflow запрашивает advisory-профили Luna/Terra/Sol; host request’ы этой сессии их содержали. В дочерних turn_context наблюдаются gpt‑5.6-sol и high, поэтому фактический per-model billing split не подтверждён.
  • Main: root rollout; subagents: 26 дочерних rollout-файлов depth=1.
  • Input: включает cached_input_tokens; cached не добавляется второй раз.
  • Output: output_tokens; reasoning_output_tokens — его подмножество.
  • Неуникальный объём: сумма rollout totals показывает billed/context workload, не deduplicated текст.
  • Cost: standard GPT‑5.6 Sol под 270K context: input $5/M, cached $0.50/M, output $30/M.
  • В логах plan_type=pro, поэтому $269.72 — API-equivalent estimate, не утверждение о начислении по подписке.

Формула

(input − cached_input) × $5/M
+ cached_input × $0.50/M
+ output × $30/M
= API-equivalent cost

# Diagnostic report

Separate the report into facts, inferences, unresolved contradictions, rejected models, canonical synthesis, confidence rationale, and the cheapest falsifying next experiment.

This is a non-implementation phase. Inspect evidence read-only; do not run tests, lint, validation, typecheck, build checks, `git diff --check`, or equivalent verification commands.

Keep uncertainty visible. An unresolved result is a completed evidence-preserving diagnosis, not a pause and not a fabricated consensus.

# Hegel workflow

**Thesis. Antithesis. Synthesis.**

## What it is

Hegel is a read-only diagnostic workflow for consequential questions that benefit from two complete competing models. It runs isolated Visionary and Pragmatist positions, freezes both artifacts before reveal, asks the same logical roles for independent synthesis, compares semantic fingerprints, optionally adjudicates once, produces one evidence-backed report, and subjects that report to separate hostile falsification.

## Use when

Use Hegel when the question has a meaningful evidence budget, multiple plausible causal or recommendation models, and a wrong consensus would be costly. Inputs become one immutable diagnostic brief: topic, question, known constraints, evidence/source requirements, stopping budget, and `mutation_policy: read_only`.

## Do not use when

Do not use Hegel for implementation, source edits, external mutation, simple fact lookup, or work without enough evidence to distinguish models. Reject-both and bounded review exhaustion finish as `unresolved_with_evidence`; they are not non-blocking stops.

## Bounded graph and report contract

The workflow runs one position fanout, one synthesis fanout, and at most one adjudication. The report owner separates facts, inferences, unresolved contradictions, rejected models, canonical synthesis, confidence, and the cheapest falsifying next experiment. A separate hostile reviewer checks source support, shared blind spots, unsupported inference, false convergence, counterexamples, and whether no action or a simpler baseline wins. At most two hostile reviews run; exhaustion projects the latest report and findings without another dialectic cycle.

The context firewall is artifact-based. Initial peers never see each other. Synthesis peers see both frozen position artifacts but not peer synthesis. Repeated logical role ids permit advisory worker restoration, while every phase remains correct with a fresh physical worker.

## Attribution

The bounded Visionary + Pragmatist, thesis-antithesis-convergence mechanism adapts the Agentic Soulmates paper's Dialectic pattern: <https://whitepaper.soulmates.md/#4-soul-architecture-designing-agentic-soulmates>. `Hegel` is this repository's project codename, not terminology attributed to the paper.
